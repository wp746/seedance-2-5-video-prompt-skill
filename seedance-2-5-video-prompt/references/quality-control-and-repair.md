## 1. Prompt preflight

### Mode and limits

- 模式匹配生成/超长/延长/编辑/转场/白模/分镜意图。
- 常规 4–30 秒，超长 30–180 秒；延长底片 ≤30 秒、单次 4–30 秒、成片 ≤60 秒。
- 输入数量不超过上限，且尽量处在甜点区。

### Reference clarity

- 每个 `@图片/@视频/@音频` 都写了读取职责。
- 视频参考写了具体时间段或只参考的动作/运镜/情绪。
- 写了不可复制的人物、背景、风格、文字或版权元素。
- 多人物逐人绑定，上传顺序与 prompt 一致。

### Story and timing

- 全片时间戳从 0 开始、递增、不重叠、覆盖目标时长。
- 每段只有一个主要戏剧任务，动作能在给定时间完成。
- 台词字数、停顿、听者反应与镜头时间匹配。
- 每段起始状态承接上一段结束状态。

### Continuity and cinema

- 身份、服装、道具、场景、光源、天气、轴线和声音已锁。
- 运镜写明起点、过程、目的与终点。
- 动作有准备、接触、惯性、环境反馈和落点。
- 非主体有自然反应；群演不克隆。
- 转场有可见物理/视听桥梁，不是空泛“丝滑转场”。

### Clean output

- 字幕、画面文字、BGM、对白、环境声的边界明确。
- 编辑任务已区分“保留原片既有文字/Logo”和“禁止新增未指定文字/Logo”，避免负向词误伤原素材。
- 关键文字若无法承受错误，已改为后期或独立简单画面。
- 负向项只针对真实风险，不与正向目标冲突。

## 2. Output scorecard

生成后按 0–2 分检查，总分 20：

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| 身份/多人 | 串脸/变脸 | 轻微漂移 | 稳定独立 |
| 场景/方向 | 空间重置/翻转 | 小误差 | 几何与方向稳定 |
| 道具/服装 | 消失/交换/变形 | 局部漂移 | 状态连续 |
| 时间戳 | 大幅错位 | 小幅提前/延后 | 基本命中 |
| 动作物理 | 穿模/无重量 | 少量不自然 | 因果与重量可信 |
| 表演 | 木偶/夸张 | 基本可用 | 微表情和反应自然 |
| 镜头/转场 | 乱漂/跳切 | 可用但普通 | 动机清晰、衔接自然 |
| 光影/材质 | AI 塑料/闪烁 | 局部问题 | 稳定真实/符合媒介 |
| 声音/口型 | 错音/串音 | 小瑕疵 | 音色、情绪、口型匹配 |
| 干净画面 | 随机字/BGM/水印 | 少量污染 | 完全符合边界 |

16–20：可用；12–15：定向修复；≤11：重新检查模式、素材职责和复杂度，不要只改形容词重抽。

## 3. Smallest-repair routing

选择能保留最多正确内容的路径：

| Failure | Repair |
|---|---|
| 单个物体、颜色、服装、路人、局部背景错误 | 智能/高级/视频编辑，写 A→B + 时间 + 保持不变 |
| 镜头整体机位不对 | 空间视角修改，锁人物动作和场景结构 |
| 原片好但后续剧情缺失 | 视频延长，写末帧状态与新增段 |
| 两段素材接不上 | 无缝转场，只补间隙且原片不改 |
| 复杂站位/运镜反复失败 | 粗颗粒白模或多宫格分镜 |
| 材质/光影渲染错误但 3D 结构正确 | 细颗粒白模分段重渲染 |
| 随机 BGM 或需保留对白 | 编辑模式去除 BGM，仅保留人声 |
| 单镜中时间戳错位 | 缩短镜头/动作链，重写区间，不先加更多描述 |
| 多人串脸/换装 | 减少同时 active 的参考，逐人绑定身份/服装/站位/声音 |
| 长视频后半漂移 | 拆为 20–30 秒段或质量门控延长，重复核心锁和首尾状态 |

## 4. Common failures

### Prompt too dense

症状：事件丢失、顺序错、动作融合。修复：删装饰性镜头；每段保留一个主动作；拆段。

### Reference pollution

症状：人物继承场景图中的陌生脸、故事板标签进入成片、动作视频风格污染。修复：写读取/忽略职责；使用更干净、更短参考；故事板改为线稿。

### Static dialogue two-shot

症状：模型忽略反打，变成僵硬双人中景。修复：选择真正的单一 master shot 并丰富表演，或把反应/插入镜头拆成独立生成段。

### Generic camera language

症状：随机环绕、镜头漂浮。修复：写相机载体、起点、速度、路径、故事目的和结束构图。

### Unmotivated transformation

症状：物体凭空出现/消失。修复：加入遮挡、接触、粒子来源、光线触发或相似物桥梁，并写过渡时间。

### Text and audio contamination

症状：随机字幕、乱码、BGM 或多余台词。修复：结尾重申 `纯净视频/无字幕/无BGM`；指定保留的唯一对白/环境声；关键文字移后期。

### Extension seam

症状：延长点姿态、相机、光线突变。修复：逐项写原片末帧的身体、视线、道具、镜头速度、光线、声音尾音，并规定新段第一动作。
