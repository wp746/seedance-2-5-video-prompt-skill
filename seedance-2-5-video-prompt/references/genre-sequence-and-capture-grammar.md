# Seedance 2.5 类型、连续叙事与拍摄语法

## 使用时机

当用户提供创意、故事梗概、剧本、分镜或要求连续多段生成时，读取本文档。纯局部编辑、去 BGM、换色或单一物体替换不必读取。

## 学习边界

本文档来自对 [Awesome Video Prompts 的 Seedance 2.5 专页](https://awesomevideoprompts.com/en/models/seedance25) 的结构化学习，而非照抄个别提示词。

2026-11-08 的页面自报收录 1,662 条 Seedance 2.5 提示词，其中 `cinematic` 标签 1,200 条。本次学习查看了该模型页面公开展示的 3 页、144 个条目，并分层阅读 28 组完整提示词，覆盖短剧、情绪戏、喜剧、恐怖、动作、追逐、超能力、产品广告、MV、Vlog、家用录像、旅行、变身、微缩世界与一镜到底。站点数量和标签是站方数据，不等于官方模型性能测试。

## 核心结论：三轴编译，不套单一模板

先决定三个相互独立的轴，再写 Prompt：

1. **类型引擎**：故事为什么往前走，观众等待什么变化。
2. **镜头拓扑**：一镜到底、经典多镜头、快切蒙太奇、卡点、主观镜头或分屏。
3. **拍摄语法**：电影机、手机 Vlog、MiniDV/家用录像、监控/执法记录仪、动画或产品影片的记录规则。

三轴必须协调。例如“路人手机偶遇录像”不能同时要求无人机俯冲、摇臂升降和完美棚拍布光；“一镜到底”不能在中途无因重置机位。

## 网站案例中可迁移的写作逻辑

### 1. 开头先建立生产合同

优秀案例普遍先写时长、画幅、媒介/拍摄形式、场景和整体质感，然后才写事件。这不是为了堆技术名词，而是先告诉模型“这是什么类型的记录”。

只写与成片有关的规格：

`[4–180 秒路由] + [画幅] + [拍摄语法] + [类型与基调] + [一句话故事任务]`

### 2. 把形容词改写为可见规则

“紧张”要改成信息差、空间逼近、呼吸、脚步声或视线变化；“真实手机感”要改成拍摄者站位、手持误差、自动对焦、曝光回抽、数字变焦和现场声；“有力量”要改成受力方向、接触点、物体惯性和环境回应。

### 3. 时间戳不是时间表，而是戏剧任务分配

每个区间只承担一个主要变化。有效句法：

`[时间] [起始构图/状态] → [触发] → [主动作] → [接触/机制] → [角色与环境反应] → [镜头结束状态] + [声音]`

### 4. 连续性的关键是“不变量”与“允许变量”

- **不变量**：人物身份、主道具、镜头路径、坐姿/动作锚点、空间几何或乐句位置。
- **允许变量**：服装、年代陈设、地点、光线、材质或能量状态。
- **转化载体**：遮挡、绕到背后、踢踏落地、节拍重音、光线扫过或实体接触。

### 5. 镜头要有拍摄者或物理载体

不写抽象的“环绕、推进、拉远”组合，而是写：谁在拍、相机在哪里、为什么移动、经过什么障碍、最后停在什么构图。一镜到底时，摄影机路径就是叙事骨架。

### 6. 声音同时负责真实感、剪辑和情绪

分开写对白、环境底噪、Foley、效果音和 BGM/静音。可用声音先行引出下一镜，或让上一镜的尾音延续到新画面。真实记录型内容不要默认添加“电影配乐”。

### 7. 负向约束用于保护机制

先写正确的人物、空间、动作和结束状态，再用 3–8 条最相关的禁止项保护一镜到底、人物身份、道具数量、物理路径、纯净画面和声音边界。

## 剧本到 Prompt 的编译流程

### A. 先做改编摘要

```text
ADAPTATION_BRIEF
- 用途/平台/画幅/时长
- 类型与子类型
- 一句话故事与核心戏剧问题
- 开场状态 → 结尾改变
- 主观角色/信息差
- 类型引擎 / 镜头拓扑 / 拍摄语法
- 角色/场景/道具/声音连续性
- 最高风险与拆段方案
```

用户给出完整剧本时，默认保留剧情、对白和人物关系；除非用户要求改剧本，只做影像化编译与生产降载。

### B. 再建立 Beat Ledger

```text
BEAT_ID / 戏剧功能 / 开始状态 / 触发
/可见主动作 / 非主体反应 / 环境证据
/镜头动机 / 对白与声音 / 结束状态
```

删掉不改变信息、关系、目标、危险、状态或情绪的装饰性 beat。如果一个 beat 同时有两个高难机制，拆段。

### C. 最后编译为自包含生成段

多段短片/短剧中，每个生成段都必须能独立理解，包含：

- 本段的入点状态和一个核心戏剧任务。
- 只重复必要的身份、服装、道具、场景和声音锚点。
- 局部时间戳从 0 开始，不用全片累计时码。
- 明确的出点状态：姿态、视线、道具、运动方向、光线和声音尾音。

## 类型编译卡

### 1. 关系/情绪短剧

- **引擎**：期待 → 异样线索 → 压住反应 → 关系揭示 → 余韵。
- **表演**：让视线、呼吸、手中物和听者反应先于大情绪。
- **镜头**：空间建立 → 关系中景 → 线索插入 → 反应特写 → 结尾落点。
- **禁忌**：开场就哭、每句话都切镜、所有人同步表情。

### 2. 复仇/误会/荒诞喜剧

- **引擎**：日常秩序 → 傲慢/误会侵入 → 延迟反应 → 物理性回敬 → 平静反应作为笑点。
- **表演**：世界和人物都要认真，不向观众解释笑话。
- **镜头**：笑点前留半拍停顿，高潮后留反应镜头。
- **禁忌**：过度夸张表演、笑点未发生就加喝彩音。

### 3. 惊悚/恐怖/悬疑

- **引擎**：安全常态 → 微弱异常 → 错误解释 → 空间侵占 → 揭示/意义反转。
- **空间**：明确黑暗区、门缝、镜子、后景或画外空间如何被侵占。
- **声音**：先声后画、近处呼吸与远处不确定声源；高潮前克制配乐。
- **禁忌**：开场亮出怪物全貌，依赖黑场/闪烁代替空间因果。

### 4. 打斗/追逐/灾难生存

- **引擎**：建立地形与目标 → 威胁发起 → 首次应对受挫 → 看见机会 → 战术动作 → 接触与余波。
- **动作**：写清谁先动、路线、接触点、受力方向、环境证据与落点。
- **镜头**：跟着战术目标移动，不只跟着“最快的东西”乱甩。
- **禁忌**：未建立地形就连续爆炸，多个灾难各自无因发生。

### 5. 奇幻/超能力/科幻 VFX

- **引擎**：世界规则 → 触发动作 → 能量/变化传递路径 → 环境证据 → 衰减、代价或新状态。
- **VFX**：光影响皮肤和环境，烟雾有风场，碎片有重力，传送有离开和重现过程。
- **禁忌**：能力无触发，特效是平面贴纸，角色规则相互污染。

### 6. 产品广告/TVC

- **引擎**：需求/问题 → 产品介入 → 使用机制 → 可见效果 → 产品英雄镜头/干净出点。
- **优先级**：产品轮廓、尺寸、材质、结构、开合方式和握持关系高于装饰特效。
- **声音**：按键、金属、玻璃、流体、食物和包装 Foley 用于证明材质。
- **禁忌**：复杂运动中同时强求长文字绝对准确；精确文字优先保护原素材或后期落版。

### 7. MV/舞蹈/时尚卡点

- **引擎**：用乐句、段落、鼓点和情绪转折建立 beat map，不是每拍都切镜。
- **连续性**：人物身份、动作轴或构图锚点不变；服装、地点、色彩在重音处变化。
- **镜头**：匹配切、动作接切、遮挡或相同轮廓转场。
- **禁忌**：随机换装导致身份变形，运镜与舞者反向抢戏。

### 8. Vlog/手机/家用录像/Found Footage

- **引擎**：拍摄者的发现路线、一个真实小任务或意外事件。
- **必写**：谁拿相机、与被摄者的关系、镜头焦段、手的逻辑、对焦/曝光反应、现场声和不完美构图。
- **年代录像**：颜色、宽容度、动态拖影、麦克风质感和当时服化道必须同一年代。
- **禁忌**：无操作者的完美稳定、广告式灯光、镜头自由穿墙。

### 9. 旅行/生活方式/纪录片

- **引擎**：一段路程、一项手上任务、天气/光线变化，最后到达有意义的空间/情绪落点。
- **镜头**：地理建立、人物行动、手部/物件细节、环境反应、终点大景。
- **声音**：路面、风、水、鸟、交通、人群和活动声建立地方感。
- **禁忌**：只有风景明信片式快切，没有路线和人物目标。

### 10. 变身/时代跳转/现实变形

- **引擎**：变化前状态 → 触发 → 中间机制 → 完成后状态 → 角色/环境验证。
- **必写**：不变量、允许变量、变化载体和变化完成后的稳定时间。
- **禁忌**：跳过中间状态，物体无因替换，连环镜头中人物或镜头路径重置。

### 11. 微缩世界/尺度反差/超现实

- **引擎**：尺度规则 → 日常物变成地形/威胁 → 适应性动作 → 到达安全点或新发现。
- **必写**：主体高度、对比物、景深、表面纹理、风/液体/落物在该尺度下的作用。
- **禁忌**：主体比例在镜头间波动，宏观物体像无重量玩具。

### 12. 动画/漫剧/强风格化

- **引擎**：剧情与真人影片一样需要状态变化，另外增加媒介 DNA。
- **必写**：2D/三渲二/黏土/毛毡/手绘/风格化 3D，线条、材质、帧感、动作夸张度、光影与特效语法。
- **禁忌**：中途漂成真人或油腻通用 3D，背景和人物使用不同媒介规则。

## 镜头拓扑选择

| 拓扑 | 适合 | 写法要点 | 主要风险 |
|---|---|---|---|
| 一镜到底 | 空间揭示、追逐、主观恐怖、环绕变迁 | 唯一路径、遮挡、速度、起止构图、无重置 | 假一镜、机位瞬移 |
| 经典多镜头 | 对白、情绪、短剧、产品使用 | 建立镜头、主体、反应、插入、落点；轴线一致 | 无意义覆盖、跳轴 |
| 硬切蒙太奇 | 广告、旅行、训练、流程、时间跨越 | 一镜一任务，用动作/形状/声音接切 | 镜头太多导致身份和产品漂移 |
| 音乐卡点 | MV、舞蹈、变装 | 先分乐句/重音，再分配动作与切镜 | 每拍都切、表演无呼吸 |
| 主观/Found Footage | 恐怖、偶遇、现场、社交媒体 | 拍摄者的手、身体、站位和受力必须成立 | 凭空第三只手、不可能机位 |
| 多层/分屏 | 对照、多地同步、社交媒体编辑 | 每层始终存在，同步变更或写清独立时序 | 层级冻结、消失、相互污染 |

## 拍摄语法锁

- **电影/剧情片**：写实际场景、调度、焦段/景深、主光来源、相机物理载体、轴线和剪辑出点。摄影机品牌只在确实改变风格时使用。
- **手机/Vlog**：写拍摄者身份、前/后置镜头、持机/支撑方式、手持误差、对焦/曝光反应、数字变焦、现场声与拍摄者反应。
- **MiniDV/复古家用录像**：锁定年代、消费级设备、麦克风声底、变焦方式、运动拖影、曝光和颜色宽容度。
- **监控/执法记录仪**：锁定安装位置、视野、时间连续、镜头界外和收音距离；不使用自由反打。
- **产品影片**：摄影机用于证明形态、材质、机制和使用结果；特写前先让空间关系可读。
- **动画/强风格化**：锁定线条、材质、帧节奏、角色变形边界和特效与环境的融合规则。

## 连续短片/短剧的全片管理

全片先建立：

- `FILM_BIBLE`：画幅、媒介、颜色、时间、地理、世界规则。
- `CHARACTER_LEDGER`：每个人的身份、外观锚点、服装状态、道具、对白、关系变化。
- `SCENE_LEDGER`：入口、出口、轴线、固定物、光源、天气和环境声。
- `STATE_LEDGER`：每段的入点/出点，伤势、污渍、道具损坏、湿度和光线变化。
- `DIALOGUE_LEDGER`：原文、说话者、语言、情绪、口型、反应和前后静默。
- `SOUND_MOTIF`：贯穿的环境声、主题音色和段与段的声音接口。

为每段写 `SEGMENT_ID / LOCAL_TIMECODE / ENTRY_STATE / CORE_CHANGE / EXIT_STATE / NEXT_HANDOFF`。全片时间线可累计，但平台内每次生成的 Prompt 使用本段 0 秒起的局部时码。

## Prompt 密度与拆段

- 4–10 秒：1 个机制、1 次主要转折，通常 1–3 个 beat。
- 10–20 秒：2–4 个可见 beat，只有 1 个高难互动或转化。
- 20–30 秒：3–6 个任务块，超过后优先拆段。
- 30–180 秒：先幕/场/段，再局部时间戳；高难动作、多人交叠对白和精确产品文字优先独立生成。

案例库中有 30 秒 12–15 镜的高密快切 Prompt，但这是风格选择，不是默认稳定答案。人物、道具、对白或空间连续性更重要时，减少镜头。

## 不盲目模仿的写法

- 大量同义形容词、SEO 标签和与叙事无关的“4K/8K/大片感”。
- 不改变故事和光学决策的摄影机/镜头品牌。
- 重复几次的人物/场景全文，或数万字却不增加可见控制的长 Prompt。
- “手持偶遇”与“完美稳定棚拍”、“一镜到底”与“快速多机位切换”等冲突指令。
- 未经用户要求的随机字幕、多语字幕、Logo 和 BGM。
- 不在实际成片中发挥作用的“精确”参数不等于可控性。

## 交付前的类型与连续性检查

1. 类型引擎是否推动状态变化，而非只有风格标签。
2. 镜头拓扑与拍摄语法是否相容。
3. 每个 beat 是否有触发、可见行为、反应/环境证据和结束状态。
4. 对白、角色反应和静默是否能装进对应时间。
5. 多段间的人物、道具、伤势、污渍、光线、运动方向和声音尾音是否交接。
6. 是否用超长 Prompt 代替必要的拆段、素材分层或后期。
7. 是否只锁需要锁的不变量，并给允许变量留出清晰通道。
