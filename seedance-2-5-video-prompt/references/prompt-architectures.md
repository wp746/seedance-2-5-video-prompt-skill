## 1. 通用编译公式

官方基础公式：

`素材描述 + 一句话概述 + 具体情节描述 + 全局补充`

生产版公式：

`输出参数/任务目标 + 参考职责 + 一句话概述 + 全局连续性锁 + 时间戳镜头脚本 + 表演/声音 + 结束状态 + 保持不变/禁止项`

### 通用骨架

```text
【输出】时长[ ]，画幅[ ]，分辨率[ ]，模式[ ]。[一句话任务目标]。

【参考素材职责】
@图片1：读取[ ]；忽略[ ]。
@视频1：只参考[时间段/动作/运镜/节奏]；不得复制[人物/背景/文字/风格]。
@音频1：只控制[角色]的[音色/情绪/语速]；台词以本文原文为准。

【全局设定与连续性】
场景/时间/天气：[ ]。
人物/主体：[ ]。
空间与方向：[ ]。
视觉风格与光线：[ ]。
表演/动作核心：[ ]。

【时间戳镜头】
[00:00–00:__] [镜头功能]：[景别/焦段/机位/运镜]；[动作因果链]；[非主体反应]；[环境/道具反馈]；[对白/声音]；结束状态[ ]。

【声音】对白[ ]；环境声[ ]；音效[ ]；BGM/静音[ ]；字幕[ ]。

【全局保持与禁止】
始终保持[身份/服装/场景/道具/方向/材质/声音]；禁止[最相关的 3–8 个失败模式]。
```

## 2. 常规 4–30 秒

### 4–15 秒

只需 1–3 个时间段。单镜头时写完整起点、过程、落点，不必强行切镜。

### 15–30 秒

使用：

1. 多模态参考层。
2. 全局世界观与防漂移层。
3. 时间戳剧本分镜。
4. 结尾与全局补充。

每个时间段写：

`开始–结束 + 阶段主题 + 物理动作/表情 + 镜头调度 + 情感潜台词 + 声音 + 结束状态`

情绪戏示例结构：

`等待 → 认命 → 重新注视 → 情绪释放 → 落点`。让微表情和呼吸递进，不要眼泪或崩溃在开头提前发生。

动作戏示例结构：

`建立空间 → 对手发起 → 主角应对失败 → 发现策略 → 关键反击 → 余波/落点`。每段承接上一段站位，禁止重置。

## 3. 30–180 秒超长视频

公式：

`全局参数 + 素材职责 + 一句话概述 + 全局连续性 + 幕/段落时间轴 + 声音系统 + 全局补充`

```text
【全局参数】全程[60/90/180]秒，画幅[ ]，分辨率[ ]，目标平台[ ]。
【故事主线】[一句话因果链和最终落点]。
【贯穿锁】[角色、服装、道具、场景、光线、镜头、声音、禁止项]。

[00:00–00:20] 开场/建立：[一个主要事件]；结束状态[ ]。
[00:20–00:45] 发展：[一个主要事件]；承接前段[ ]；结束状态[ ]。
[00:45–01:10] 转折：[ ]。
[01:10–01:30] 高潮：[ ]。
[01:30–01:40] 收束：[ ]。

【全局补充】全程动作连贯、叙事清晰；禁止人物/服装/场景中途变异；[字幕/BGM/对白规则]。
```

长视频按剧情密度选择 10–30 秒的段落块。对白密集时缩短块长，并逐字分配台词。

## 4. 视频延长

### 连续一镜到底

```text
参考@视频1，向后延长[ ]秒。严格从原视频最后一帧继续：起始时人物[身体姿态/视线/手中道具/情绪]，相机[位置/运动方向/速度]，场景[光线/天气/声音尾音]。
新增段发生：[动作因果链/对白/镜头]。
要求延长自然、动作与镜头速度连续、物体状态连续；禁止生硬切镜、姿态重置、物体凭空出现、方向翻转。
新增段结束状态：[ ]。
```

### 带创意转场

公式：`转场类型 + A 镜头出点 + 过渡载体 + B 镜头入点 + 几何/运动匹配 + 禁止项`

```text
参考@视频1，向后延长[ ]秒。切镜处使用[遮挡/相似物/叠化/甩镜/粒子/水墨]转场。
镜头 A：[原片结尾状态]；[载体]以[方向/速度]遮满或占满画面。
过渡中：[颜色/纹理/粒子/形状]逐渐变为[ ]。
镜头 B：[新场景与景别]；保持载体的位置、大小、方向和速度连续。
原视频不修改；禁止黑屏、跳帧、闪烁、硬切和无因物体。
```

自然镜头切换最通用；淡入淡出适合开头、结尾和时间跳跃；叠化适合回忆/梦境；白闪/黑闪适合重音；擦除/遮挡适合明确方向的空间迁移。

## 5. 智能/高级/视频编辑

### 文本编辑

公式：`生效时序 + 目标 + A→B 变化 + 变化方式 + 保持不变项 + 音频处理`

```text
在原视频[00:03–00:08]，将[具体目标 A]替换/删除/增加为[目标 B]。[出现/变化过程]。
仅修改[ ]；人物身份、动作轨迹、姿势、镜头、场景几何、原始光影、其他道具和未指定时间段全部保持不变。
[原片已有的品牌 Logo、包装文字、字幕或标识按需求明确保留/删除]；禁止新增未指定文字、Logo、字幕或水印。
[保留人声并去除 BGM / 保持完全静音 / 保留原音]。
```

### 圈选/标记编辑

公式：`标注工具与方位 + 目标 + 变化 + 生效时序 + 保护区`

```text
将[红框内/蓝色箭头指向/定位点处/红线左侧]的[目标]从[A]改为[B]，从第[ ]秒开始[逐渐/立即]生效并保持到结尾。
标注外区域、人物皮肤、动作、镜头、背景和音轨保持不变；补全被遮挡区域的原始纹理、透视与光影，不留残影和补丁。
原片已有文字、Logo、字幕和包装标识除非被明确列为修改目标，否则保持原样；仅禁止新增未指定文字或标识。
```

空间视角修改再加：

`把原[平视/第三人称/多机位]改为[高空俯拍/低机位/第一人称/固定正面]；保持人物动作、场景结构和主体比例不变；合理外推原画面外空间。`

## 6. 白模

### 粗颗粒动态骨架

公式：`参考声明 + 模型映射 + 时间线剧情 + 场景 + 整体收束`

```text
@视频1只参考运镜、动作、动线、站位、光影变化和节奏；不保留白模材质。
将@视频1中的[颜色/形状模型 A]映射为@图片1的[角色 A]；[模型 B]映射为@图片2的[角色 B]；[模型 C]映射为@图片3的[道具]。
[时间戳剧情与完整四肢动作链]
背景参考@图片4；相机路线、轴线和站位严格跟随@视频1。
最终风格[ ]；保持身份/材质/场景/声音一致；无白模残留、无穿模、无坐标线。
```

### 细颗粒渲染

公式：`渲染指令 + 分段渲染 + 场景 + 全局材质/光影锁`

```text
将@视频1的完整白模动画渲染为最终成片；保留几何、动作、相机和切镜。
0–5s：[背景、材质、光线、色调、特效]。
5–11s：[转场触发点与新场景渲染]。
11–19s：[产品/角色最终材质与落版]。
移除白模轨迹线、坐标轴、相机 cone 和 viewport UI。全程保持[材质/颜色/身份/光学]一致。
```

## 7. 无缝转场

```text
将@视频1与@视频2无缝衔接，但不修改两段原视频。
@视频1结尾：[镜头运动和触发物]；触发物以[方向/速度]靠近并填满画面。
中间补帧：[形状/颜色/纹理/粒子/光线]连续变化。
@视频2开头：[同一或匹配物]以对应位置、大小、方向和速度离开/展开，带出新场景。
锁定匹配：中心位置[ ]、尺寸[ ]、运动方向[ ]、速度[ ]、色彩变化[ ]、相机惯性[ ]。
禁止修改原片、黑屏、跳帧、硬切、闪烁；原片已有字幕或 Logo 保持原样，仅禁止新增未指定字幕、Logo 或水印。
```

桥接载体可选：伞面/衣摆/纸飞机/镜子/水洼反光/门框/粒子/气泡/烟雾/光晕/相似圆形/同方向甩镜。

## 8. 多宫格分镜

```text
@图片1是[N]格连续分镜；每格代表一个完整镜头，不是人物设定板。
@图片2控制角色 A 身份；@图片3控制角色 B；@图片4控制场景。

SHOT 01 / 0–3s：[景别、构图、动作、运镜、声音、出点]；对应分镜第1格。
SHOT 02 / 3–6s：[ ]；对应第2格。
...

严格按分镜顺序；提示词补齐格与格之间的动作过程。人物、服装、比例、场景轴线不变。分镜图中的线稿、标签、箭头、文字不得出现在成片。
```

分镜图推荐简单线稿/火柴人；角色身份用独立参考图，不让分镜重新设计面孔。

## 9. 纯音频、音色、多人和绿幕

### 纯音频驱动

```text
@音频1控制完整节奏、情绪和声场。根据[节拍/语音内容/环境音]生成[视觉故事]。
[时间戳]声音事件发生时，画面执行[动作/切镜/光线变化]。不生成额外人声/BGM。
```

### 音色

```text
角色 A 的音色参考@音频1：年龄感[ ]、音高[ ]、音色[ ]、气息[ ]、语速[ ]、口音[ ]。
以[情绪和潜台词]说：“原始台词”。口型严格匹配；不复制参考音频的背景噪声和无关内容。
```

### 多人

逐人写 `身份参考 + 服装 + 初始站位 + 动作顺序 + 关系 + 声音`。明确人数；同框交互写接触点、遮挡关系和谁先动。禁止串脸、换装、交换道具、克隆脸和同步木偶反应。

### 绿幕

```text
从@视频1精细提取[人物/物体]前景，保留发丝、半透明边缘、动作和原始形变；去除绿色溢色。
将其合成到@图片1/@视频2的新场景；匹配透视、机位、脚底接触、运动模糊、光向、色温、阴影和环境反射。
前景身份和动作不变；背景无绿色残留、边缘抖动、穿帮和漂移。
```
