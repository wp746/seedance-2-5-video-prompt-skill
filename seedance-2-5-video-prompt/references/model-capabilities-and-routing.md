## 1. 核心升级

Seedance 2.5 相比 2.0 的重要变化：

- 常规生成从 4–15 秒扩展到 4–30 秒。
- 新增 30–180 秒超长视频模式。
- 新增视频延长：以 ≤30 秒视频为底片，向前/向后延长 4–30 秒，最终最长 60 秒。
- 支持文本时间戳对动作、对白、镜头和转场做秒级控制；也能理解明确帧号。
- 多模态输入数量和总时长显著扩大，支持纯音频输入。
- 更少随机字幕/BGM；更强 BGM 分离、音色、多语种、多人、复杂动作与切镜一致性。
- 新增或增强智能/高级/视频编辑、局部消除/替换、机位重构、绿幕、白模、无缝转场、多宫格分镜与创意迁移。

## 2. 参数上限与甜点区

### 官方上限

| Input/output | Seedance 2.5 |
|---|---|
| 图片 | 最多 30 张，建议 4K 以内 |
| 参考视频 | 最多 10 段；单段约 2–30 秒；总时长 ≤30 秒 |
| 参考音频 | 最多 10 段；单段约 2–30 秒；总时长 ≤30 秒 |
| 纯音频驱动 | 支持 |
| 常规输出时长 | 4–30 秒，约 97–721 帧 |
| 超长视频 | 30–180 秒 |
| 输出分辨率 | 480p、720p |

手册给出的底层容差：单段参考视频/音频约 1.8–30.2 秒，总时长约 30.2 秒。面向创作者输出时使用界面整数上限，不鼓励卡容差。

### 稳定甜点区

| Scenario | Recommended |
|---|---|
| 以音视频绑定主体 | 1–5 个主体；6–10 个稳定性下降 |
| 主体音视频时长 | 5–10 秒更稳 |
| 以图片绑定主体 | 1–8 个主体；9–12 个稳定性下降 |
| 多视角主体 | 1–5 主体可单图多视图；超过 5 主体优先多图单视图/多图多视图 |
| 编辑已有视频 | 20 秒内更稳 |
| 视频编辑参考图 | 1–5 张更稳；6–8 张稳定性下降 |

决策原则：先以甜点区设计；只有业务价值明显高于抽卡成本时才接近平台上限。

## 3. 模式路由

### STANDARD_GENERATE

适用：4–30 秒全能参考、首帧、首尾帧、文本/图/视频/音频生成。

优点：时间戳最精确，复杂动作、对白、多人和多镜头最易控制。20–30 秒必须写全局锁和时间段。

### ULTRA_LONG

适用：30–180 秒 Vlog、纪录片式过程、氛围片、环境叙事、教程、连续长镜头、低密度剧情。

风险：长时记忆虽增强，但密集角色状态、频繁换景、长对白和高难动作仍会积累漂移。先写幕/段落，再写段内时间戳；不要逐秒塞满 180 秒。

### EXTEND

适用：逐段验收、延续动作、剧情反转、镜面/遮挡/空间穿越、把满意镜头继续写下去。

规则：

- 底片必须 ≤30 秒。
- 延长 4–30 秒。
- 最新产物仍 ≤30 秒时可以继续套娃；最终最长 60 秒。
- 提示词只作用于新增区间，原区间保留。
- 明确 `向前延长` 或 `向后延长`、延长时长、连接方式和新段结束状态。

### SMART_EDIT / VIDEO_EDIT

适用：A→B 替换、删除、增加、改色、改服装、去 BGM、保留人声、改绿幕、指定时间段局部修复。

- 智能编辑：用文本修改已生成视频。
- 高级编辑：对生成视频增加框选、箭头、画笔、定位点等精细控制。
- 视频编辑：对本地上传视频进行类似高级编辑。

默认写 `修改什么 + 怎么变 + 何时生效 + 其余保持不变`。只有授权素材才处理水印或版权标识。

### SEAMLESS_TRANSITION

适用：保留两段原片，只补中间间隙。以遮挡物、形状、粒子、颜色、动作、视线或运动方向作为桥梁。

必须明确两段原视频不修改，并锁定桥接元素的位置、大小、方向、速度和运动连续性。

### WHITE_MODEL

- 粗颗粒度：简单几何体做动态骨架，重点参考运镜、动线、站位、光影变化、节奏；当前更稳。
- 细颗粒度：完整 3D 模型/材质结构直接渲染，重点替换材质、光影、风格和场景。

粗白模中带四肢/翅膀时，写完整动作序列；若能避免，优先用无四肢几何体表达轨迹。细白模输入前清理轨迹线、坐标轴和相机 cone。

### MULTI_PANEL_STORYBOARD

适用：强叙事、多镜头和严格构图。推荐简单线稿/火柴人分镜，不用写实画面污染身份。提示词补齐每格：镜头编号、主体映射、景别、构图、动作、运镜、声音和时间。

## 4. 2.0 → 2.5 迁移

### 保留的 2.0 方法

- 每个参考只负责一种控制。
- 先锁角色/场景/道具/风格/方向/声音，再写镜头。
- 写首尾状态、环境反馈、动作惯性、非主体反应。
- 复杂任务拆分并逐段验收。
- 精确文字、字幕和 UI 仍需保守处理。

### 需要删除或改写的旧规则

- `每段 ≤15 秒` → 常规生成可 4–30 秒，但复杂度高仍可主动缩短。
- `参考图 ≤9` → 上限 30；稳定策略仍是只传当前镜头所需素材。
- `参考视频/音频总长 ≤15 秒` → 2.5 为 30 秒。
- `不能只传音频` → 2.5 支持纯音频。
- `随机字幕/BGM 很难控制` → 2.5 明显改善；仍明确写 clean/静音边界。
- `多人容易双胞胎/换脸错位` → 2.5 改善；仍逐人绑定身份、服装、站位与声音。

## 5. 能力边界

- “改善”不是“保证”。复杂交叠肢体、密集群像、长对白和高难物理仍需复杂度预算。
- 时间戳能控制时序，但不能补救同一秒内不可能完成的动作。
- 180 秒能力适合低到中等事件密度；高事件密度优先分段。
- 精确长文本、品牌包装、字幕和招牌仍是高风险。必要时隔离成简单大字镜头或后期完成。
- 创意迁移要写清迁移内核与排除项：可迁移镜头节奏、情绪、网感、动作机制；不可默认复制人物、场景、品牌或版权 IP。
- 空间视角修改需要写“新机位 + 保持不变项 + 外推空间逻辑”；不要只写“更电影感”。
