# Seedance 2.5 常用创作案例

以下案例用于演示 Skill 如何根据任务选择模式、分配参考职责，并输出可直接复制的生产提示词。实际使用时替换素材编号、角色设定、品牌信息和对白即可。

## 1. 15 秒护肤品竖屏 TVC

模式：`STANDARD_GENERATE / 全能参考`

上传顺序：

- `@图片1`：真实产品白底图。
- `@图片2`：灯光、色彩和材质氛围参考图。

```text
【输出】
生成一条完整15秒、9:16、720p的高端护肤精华产品广告。核心卖点是纯净、清透、精密和轻盈吸收。纯净成片，不生成字幕、旁白、BGM、标题或额外广告语。

【参考素材职责】
@图片1只控制精华瓶的瓶身比例、泵头结构、玻璃厚度、液体颜色、Logo、包装文字和产品材质；忽略原图白底、拍摄角度、阴影和布光。
@图片2只控制冷银蓝色调、湿润黑色石材、轮廓光和水面反射；不读取其中的产品、人物、文字或品牌。

【产品锁定】
全片始终是@图片1中的同一瓶产品。瓶身比例、泵头、Logo位置、液体高度和玻璃结构保持不变，不得重新设计。包装已有Logo和文字作为原始纹理整体锁定，不改写、不增删、不生成乱码；当镜头角度无法准确呈现文字时，以不清晰但不错误为优先。

【时间戳镜头】
[00:00–00:03]
85mm微距固定镜头。黑色湿润石材表面先处于低照度状态，产品以真实实体完整站立在画面中央，只有瓶身边缘出现一道冷银色轮廓光。环境水汽缓慢移动，但产品不旋转、不变形。

[00:03–00:07]
50mm低机位，电控滑轨从画面左侧缓慢横移约40厘米。狭窄光带从瓶身左侧扫向右侧，依次揭示玻璃厚度、液体透明度和泵头金属细节。Logo和包装纹理随瓶身透视自然变化，不漂移。镜头结束时产品形成稳定的四分之三侧面英雄角度。

[00:07–00:11]
100mm微距。一颗透明水滴从泵头边缘自然凝结，受重力影响沿玻璃缓慢滑落，经过瓶身时产生真实折射、焦散和轻微放大效果。水滴不改变Logo和产品结构，石材表面出现对应的柔和反光。

[00:11–00:15]
50mm正面英雄镜头，滑轨极慢后移。产品保持画面中央，背景形成冷银蓝渐变，石材上的薄水层出现克制涟漪。最后两秒稳定停留，为后期排版保留画面上方干净负空间，不在模型内生成文字。

【声音】
仅保留极轻的水滴、湿润石材和玻璃触碰空间声。无对白、无旁白、无BGM、无歌曲。

【全局保持与禁止】
保持产品尺寸、液体高度、Logo位置、包装纹理和玻璃材质一致。禁止瓶身变形、泵头增生、文字乱码、Logo漂移、产品复制、液体穿模、无来源粒子、随机旋转、快速环绕、塑料材质、字幕和新增文字。
```

## 2. 30 秒双人对白短剧

模式：`STANDARD_GENERATE / 30秒常规生成`

上传顺序：

- `@图片1`：女主身份与服装。
- `@图片2`：男主身份与服装。
- `@图片3`：深夜写字楼电梯厅场景。

```text
【输出】
生成一条完整30秒、16:9、720p的写实真人情感短片。深夜写字楼电梯厅，一对刚分开的恋人归还钥匙，关系在克制的对话中出现微小转机。表演生活化、不煽情。

【参考素材职责】
@图片1只控制女主的面部身份、发型、体型、妆容和服装；忽略背景、姿势与原图光线。
@图片2只控制男主的面部身份、发型、体型、皮肤质感和服装；忽略背景、姿势与原图光线。
@图片3只控制电梯厅空间、墙面材质、电梯位置、顶灯和夜间冷色环境；不读取其中的人物、文字和标识。

【连续性锁】
女主全程位于画面左侧，男主位于画面右侧，两人相距约1.2米，保持同一条动作轴。女主右手拿着一枚普通银色钥匙；钥匙的形状、数量和位置连续一致。冷白顶灯为主光，远处办公室透出极弱暖光。真实肤质、轻微疲惫、低饱和色彩，镜头稳定克制。

女主表面平静，实际在等待男主挽留；男主并不是来拿钥匙，而是在压住紧张。两人都不哭、不争吵、不拥抱。

【时间戳镜头】
[00:00–00:05]
35mm固定远中景。深夜空旷电梯厅，电梯门打开，女主从左侧电梯走出。男主已经站在画面右侧等待。女主看见他后脚步停顿半秒，随后继续走近；男主肩颈轻微绷紧，没有迎上去。

[00:05–00:10]
50mm稳定双人中景。女主在距离男主约1.2米处停下，从右手掌心露出银色钥匙，手臂只向前伸出一半。男主低头看钥匙，又重新看向她，没有伸手。两人保持自然呼吸。

[00:10–00:14]
85mm女主近景。女主努力保持平静，声音较低、语速偏慢，以普通话逐字说一次：“钥匙还你。”说完后手仍停在两人之间，眼神没有移开。

[00:14–00:19]
85mm男主近景。男主先看钥匙，再抬眼看她，轻吸一口气，以稳定但略紧张的普通话逐字说一次：“我不是来拿钥匙的。”女主在画外保持沉默，不插话。

[00:19–00:23]
50mm过肩镜头看女主。她眉心轻微松动，但仍然戒备，收回钥匙约十厘米，以克制语气逐字问：“那你来干什么？”

[00:23–00:28]
50mm反打男主。男主没有靠近，只将手从口袋中拿出，自然垂在身侧，眼神认真，语速稍慢，逐字说：“来问你，明天还一起吃早餐吗？”口型严格同步，不笑得过于明显。

[00:28–00:30]
回到稳定双人中景。女主没有直接回答，只缓慢合拢握着钥匙的手，肩膀轻轻放松，嘴角出现几乎不可察觉的笑意。男主读懂她的反应，但仍保持原位。电梯门在背景缓慢关闭，画面结束。

【声音】
只有电梯运行底噪、远处空调声、轻微衣料声和四句指定对白。无其他人声、无旁白、无BGM。四句对白不得改写、交换、重复或添加。

【全局保持与禁止】
保持两人身份、服装、左右关系、钥匙状态和场景光线一致。禁止串脸、换装、越轴、突然靠近、拥抱、哭泣、争吵、夸张笑容、随机路人、随机切镜、字幕、Logo、水印和画面文字。
```

## 3. 60 秒治愈系陶艺纪录片

模式：`ULTRA_LONG / 超长视频`

无需上传素材，纯文本生成。

```text
【全局参数】
使用Seedance 2.5超长视频模式，一次生成完整60秒，9:16、720p。治愈系写实人物纪录片，一位年轻陶艺师在清晨完成一只海蓝色手工茶杯。单人物、单工作室、低事件密度，动作真实，节奏舒缓。

【人物锁】
陶艺师为28岁东亚女性，清瘦体型，黑色短发别在耳后，脸上有少量雀斑，穿米白色旧棉麻衬衫和靛蓝围裙，袖口卷到小臂。全片保持同一张脸、发型、服装与围裙污渍。表演专注、安静，不看镜头。

【道具锁】
同一块灰白陶泥逐渐成为一只有小圆耳把手的茶杯。杯口略微不规则，杯壁有一条手工压痕，最终为低饱和海蓝色釉面。杯子的尺寸、压痕和把手方向在所有阶段保持可追踪，不突然更换成另一只杯子。

【场景锁】
南方老城的一间小型陶艺工作室。旧木窗位于画面左侧，拉坯机位于中央，工具架位于右后方，窑炉位于最深处。晨光由冷青逐渐转为浅金色，空间布局不得重置。自然毛孔、陶泥颗粒、木纹、釉面和衣料褶皱清晰，不使用梦幻滤镜。

【时间戳叙事】
[00:00–00:08] 开店：陶艺师推开旧木门，挂起布包，卷好袖口，打开窗户。结束时她把一块灰白陶泥放在工作台中央。

[00:08–00:18] 揉泥：她用掌根反复推压陶泥，身体重心随动作前移和回收。泥料受力变形，手掌沾上泥屑。结束时泥团被放在拉坯机中央。

[00:18–00:31] 拉坯成形：她湿润双手，扶正泥团、提拉杯壁、收窄杯口。手指压力与陶泥形变同步。结束时形成一只保留轻微压痕的无把手湿坯茶杯。

[00:31–00:40] 修整与安装把手：她修平杯底，将同源陶泥弯成小圆耳把手，刮毛、蘸泥浆、压紧连接点并抹平接缝。把手安装在杯身右侧，不穿模、不自动出现。

[00:40–00:49] 上釉：她将干燥后的同一只杯坯缓慢浸入海蓝色釉浆，再垂直提起。釉浆受重力向下流淌，多余釉液滴回容器。

[00:49–00:55] 时间流逝：她将杯子放入窑炉，窑炉门遮满画面完成时间跳跃。遮挡后从同一方向打开窑炉，窗外已是温暖上午；她取出烧制完成的同一只海蓝色茶杯。

[00:55–01:00] 收束：她把茶杯放在窗边旧木桌上，倒入热茶。热气缓慢升起。她双手捧杯，低头观察釉面，轻轻放松呼吸。

【声音系统】
只保留开门、窗户、揉泥、拉坯机、湿泥、工具、釉浆、窑炉、倒水、鸟鸣和远处环境声。无对白、无旁白、无BGM。

【全局禁止】
禁止人物变脸、换装、工作室重置、杯子复制、把手换边、杯型突变、陶泥穿手、液体逆重力、工具漂浮、卡通化动作、随机字幕、Logo、水印和画面文字。
```

## 4. 将 15 秒原片延长到 30 秒

模式：`EXTEND / 向后延长15秒`

上传顺序：

- `@视频1`：夜间列车中的女主，最后一帧列车进入隧道。

```text
参考@视频1，向后延长15秒，使最终成片总长30秒。原视频前15秒完全不修改，只生成新增的00:15–00:30区间。

【原片末帧接口】
严格从@视频1最后一帧继续：女主坐在车窗左侧，保持同一张脸、发型、深灰色外套和座位姿态；她的侧脸与车厢灯光映在玻璃上，右手搭在膝上的旧明信片旁。列车正在隧道中高速前进，镜头以非常缓慢的速度向她推进，车轮与铁轨声连续存在。

【新增时间线】
[00:15–00:20] 保持原机位、焦段、推进方向和速度。隧道灯从窗外规律掠过，明暗变化真实扫过女主侧脸。她将目光从玻璃倒影缓慢移向窗外。

[00:20–00:24] 列车自然驶出隧道。隧道出口的冷白亮斑逐渐扩大，带出清晨山谷和浅金色天光。相机自然降低曝光，保护人物和窗外高光。

[00:24–00:27] 女主拿起膝上的旧明信片，只看图像一面，不出现可读文字。她用拇指轻轻摩挲纸片边缘，再抬眼看向远山。

[00:27–00:30] 镜头停止推进。窗外晨雾缓慢后退，阳光落进她的眼睛。她轻轻呼出一口气，嘴角出现克制的释然。结束时明信片仍握在右手，列车继续向前。

【声音】
无缝延续@视频1的车轮、铁轨和车厢低频声；驶出隧道后加入极轻的空间变化。保留原片已有声音，不新增对白、旁白或BGM。

【禁止】
禁止连接处黑屏、硬切、曝光闪烁、姿态重置、镜头速度突变、列车方向翻转、衣服变化、明信片消失、窗外景色瞬间替换、字幕和新增文字。
```

## 5. 局部替换产品并去除 BGM

模式：`VIDEO_EDIT / 视频编辑`

上传顺序：

- `@视频1`：18秒咖啡馆原视频。
- `@图片1`：目标暗红色陶瓷杯。

```text
编辑@视频1。

在原视频00:06–00:13期间，将人物手中出现的白色一次性纸杯完整替换为@图片1中的暗红色陶瓷杯。

【目标替换】
读取@图片1的杯型比例、暗红色釉面、把手形状、杯口厚度和表面细小反光；忽略参考图的背景、桌面、相机角度、阴影和其他物体。

替换后的陶瓷杯必须严格跟随原纸杯的空间位置、移动轨迹、旋转角度和持握动作。人物手指应根据遮挡关系正确出现在杯子前方或后方，不穿模。杯子的透视、景深、运动模糊、色温、环境反射和接触阴影与原镜头一致。

原纸杯中的热饮和蒸汽继续保留；蒸汽从新陶瓷杯口自然升起。杯子在00:06第一次进入画面时已经完成替换，直到00:13离开画面，不进行可见变形或魔法变化。

【保护项】
仅修改指定时间段内的纸杯。人物面部、发型、服装、手部动作、身体姿势、桌面物品、咖啡馆空间、镜头运动、光线、景深以及未指定时间段全部保持原样。

原片已有招牌、包装文字、Logo和装饰标识保持原样；禁止新增未指定文字、字幕、Logo或水印。

【声音编辑】
移除原视频全部背景音乐，只保留人物原有对白、咖啡馆环境声、杯子放置声、衣料声和其他同期声音。不要改变人声内容、音色、口型和环境混响。

【禁止】
禁止残留纸杯边缘、杯型跳变、把手换边、杯子漂浮、手指穿模、蒸汽断裂、局部补丁闪烁、背景重绘、人物变脸和镜头变化。
```
