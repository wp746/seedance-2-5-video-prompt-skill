# Seedance 2.5 Video Prompt Skill

一个面向 AI 视频创作者的即梦 Seedance 2.5 提示词导演 Skill。

它不是提示词词库，而是一套从创意、剧本、参考素材或已有视频出发，自动完成模式选择、素材职责划分、连续性锁定、时间戳分镜、表演与声音设计，以及生成后最小返修的生产工作流。

> 非即梦官方项目。模型参数与能力边界依据用户提供的 Seedance 2.5 使用手册整理，并结合 Seedance 2.0 时期的实际生产方法完成迁移和前向测试。

## 能做什么

- 把一句模糊创意扩写成可直接复制到即梦的完整视频 Prompt。
- 把剧本、分镜或故事梗概编译成 4–30 秒时间戳镜头脚本。
- 为 30–180 秒超长视频规划幕结构、连续性与声音系统。
- 根据角色图、场景图、动作视频和音频建立明确的参考素材职责。
- 为双人对白、多人群像、动作戏、TVC、MV、漫剧、Vlog、文旅和纪录片选择不同的镜头策略。
- 延长满意的已有视频，并处理末帧姿态、镜头速度、光线和声音接口。
- 对本地视频执行局部替换、删除、改色、换装、去 BGM、保留人声和视角重构。
- 为无缝转场、白模渲染、多宫格分镜、绿幕合成和纯音频驱动画面编写专用 Prompt。
- 在生成后依据失败类型选择最小返修路径，尽量保留已经正确的内容。

## 核心特点

### 1. 先路由，后写提示词

Skill 不会把所有任务都当成普通文生视频，而是先选择主模式：

| 创作意图 | 推荐模式 |
|---|---|
| 文本、图片、视频或音频生成 4–30 秒 | `STANDARD_GENERATE` |
| 一次生成 30–180 秒 | `ULTRA_LONG` |
| 给已有片段向前或向后续写 | `EXTEND` |
| 修改即梦生成的视频 | `SMART_EDIT` |
| 修改本地上传的视频 | `VIDEO_EDIT` |
| 保留两段原片并补中间过渡 | `SEAMLESS_TRANSITION` |
| 用 3D 白模控制动作、走位或渲染 | `WHITE_MODEL` |
| 用多宫格故事板控制多镜头 | `MULTI_PANEL_STORYBOARD` |
| 替换或合成绿幕背景 | `GREENSCREEN` |
| 只使用音频驱动画面 | `AUDIO_ONLY` |

### 2. 区分平台上限与稳定甜点区

Skill 了解 Seedance 2.5 的主要输入输出边界，同时不会为了用满上限而堆叠素材：

- 常规输出：4–30 秒。
- 超长视频：30–180 秒。
- 图片：最多 30 张。
- 参考视频：最多 10 段，总时长不超过 30 秒。
- 参考音频：最多 10 段，总时长不超过 30 秒。
- 视频编辑通常控制在 20 秒内、参考图控制在 1–5 张更稳定。

复杂任务会主动减少参考、缩短生成区间或拆成可验收段落。

### 3. 继承 Seedance 2.0 的生产纪律

保留经过实际创作验证的方法：

- 每个参考只承担清楚的职责，并写明读取项与忽略项。
- 先锁角色、场景、道具、轴线、风格和声音，再写镜头。
- 先制作镜头计划，再编译最终 Prompt。
- 写清每个镜头的开始状态、动作因果链、环境反馈和结束状态。
- 对失败片段优先局部编辑、延长或补转场，而不是整条重抽。

同时删除 2.0 时期已经过时的 15 秒、9 张图等硬限制。

### 4. 输出是导演指令，不是形容词堆砌

“高级、真实、有电影感”会被翻译成可以观察和验收的控制信息，例如：

- 景别、焦段、机位、载体、速度和镜头结束构图。
- 光源方向、色温、对比、表面材质与空间层次。
- 呼吸、视线、手指、肩颈、重心和非说话者反应。
- 预备、发力、接触、受力、惯性、环境响应和动作落点。
- 对白、环境声、拟音、BGM、字幕和纯净成片边界。

### 5. 生产级连续性和返修

Skill 会建立六类连续性锁：

`CHARACTER_LOCK`、`SCENE_LOCK`、`PROP_LOCK`、`STYLE_LOCK`、`SCREEN_DIRECTION_LOCK`、`AUDIO_LOCK`。

生成后可按身份、空间、道具、时间戳、动作物理、表演、镜头、材质、声音和干净画面十个维度验收，并将问题路由到最小返修方式。

## 适用场景

- 真人短剧、双人对白、情绪戏和多人群像。
- 动作、追逐、武打、超能力与复杂物理交互。
- 美妆、食品、汽车、3C、服装和品牌情绪 TVC。
- MV、卡点视频、舞蹈和纯音频视觉化。
- 漫剧、动画、黏土、毛毡、三渲二和风格化 3D。
- Vlog、纪录片、文旅宣传、人物故事和制作过程。
- 30–180 秒低到中事件密度的长视频。
- 已有视频续写、局部替换、去除 BGM、保留对白和修复错误。
- 白模控制、无缝转场、绿幕合成与多宫格分镜。

## 使用规则

1. 一个生成段只承担一个核心戏剧任务或情绪转折。
2. 每个 `@图片N`、`@视频N`、`@音频N` 都必须写清读取内容和忽略内容。
3. 用户给出的对白、品牌名、数字和标点视为锁定资产，不擅自改写。
4. 20–30 秒使用完整时间戳、全局连续性锁和明确结束状态。
5. 60–180 秒先写幕和段落，再写段内时间戳；密集对白和高难动作优先拆段。
6. 精确包装文字、字幕、招牌和长文本仍属于高风险内容，优先保护原素材或后期排版。
7. 视频编辑必须写成“时间范围 + A→B + 变化方式 + 保持不变项 + 音频处理”。
8. 视频延长必须写明方向、时长、末帧接口、镜头惯性和新增段结束状态。
9. 负向约束只针对真实失败风险，不能与需要保留的原片内容冲突。
10. 生成失败时先选择能保留最多正确内容的最小返修方式。

## 安装

克隆仓库后，把 Skill 目录复制到 Codex Skills 目录：

```bash
git clone https://github.com/wp746/seedance-2-5-video-prompt-skill.git
cp -R seedance-2-5-video-prompt-skill/seedance-2-5-video-prompt ~/.codex/skills/
```

重新启动 Codex，或开启一个新任务，让 Skill 被自动发现。

也可以把 `seedance-2-5-video-prompt` 文件夹安装到其他兼容 `SKILL.md` 的 Agent Skills 目录。

## 使用方法

显式调用：

```text
使用 $seedance-2-5-video-prompt，把下面的故事制作成即梦可直接使用的30秒提示词……
```

也可以自然语言触发：

```text
我有两张演员定妆图和一张便利店场景图，帮我写一个30秒Seedance 2.5双人对白短剧。
```

```text
把这条15秒视频向后延长15秒，人物和镜头不要跳，最后从雨夜过渡到清晨。
```

```text
将原视频6到12秒的白色纸杯替换成参考图里的红色陶瓷杯，并去掉BGM、保留人声。
```

默认输出包含：

1. 模式、时长与风险判断。
2. 参考素材上传顺序和职责。
3. 可直接复制的完整 Prompt。
4. 生成后的验收重点与最小返修建议。

## 案例

[常用创作案例](examples/common-scenarios.md)包含五组完整示例：

1. 15 秒护肤品竖屏 TVC。
2. 30 秒双人对白短剧。
3. 60 秒治愈系陶艺纪录片。
4. 将满意的 15 秒镜头延长到 30 秒。
5. 局部替换产品并移除 BGM。
